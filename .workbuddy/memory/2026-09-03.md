## ⚠️ 环境坑：沙箱内 git ref 写入静默失效

- 现象：`git checkout -b` / `git branch` / `git commit` 均"声称成功"，但 `.git/refs/heads/` 下 ref 文件不创建、commit 还会删掉旧 ref 文件 → HEAD 悬空、branch broken
- 根因疑似：git 更新 loose ref 用的 `.lock → rename` 在本 Bash 沙箱中被拦截（普通文件写入正常，probe 通过）
- 规避：commit 后 `git rev-parse <短sha>` 取全量，再 `printf '%s\n' <full-sha> > .git/refs/heads/<branch>`（需 mkdir -p 分支目录）；或在用户自己的终端操作 git
- 已恢复：feature/agent-investigation 与 master 均指向正确 commit，log/status 正常
